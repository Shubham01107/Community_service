# Digital Saathi – Digital Awareness & Online Safety Platform

## About the Project
Digital Saathi is a digital awareness platform developed to educate students, senior citizens, and people with limited digital knowledge about safe and responsible internet usage.

The project focuses on spreading awareness about common online threats, cyber fraud, phishing attacks, and digital payment safety through simple learning resources and interactive activities.

## Objectives
- Promote digital literacy and online safety awareness.
- Educate users about common cyber frauds and scams.
- Encourage safe digital payment practices.
- Help users understand online privacy and security.
- Make digital safety education accessible and easy to understand.

## Key Features
- Digital safety learning modules.
- Information about OTP and UPI fraud.
- Awareness about phishing attacks and fake links.
- Password security guidelines.
- Social media privacy tips.
- Interactive quiz with 10 questions.
- Online safety awareness resources.

## Topics Covered
1. Online Safety
2. UPI and OTP Security
3. Phishing and Fake Links
4. Password Protection
5. Social Media Privacy
6. Responsible Internet Usage
7. Cyber Fraud Awareness

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)

## Installation & Setup

### 1. Clone the Repository
```bash
git clone <repository-url>
```

### 2. Navigate to the Project Folder
```bash
cd "Digital Saathi"
```

### 3. Create a Virtual Environment
```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

Windows:
```bash
venv\Scripts\activate
```

### 5. Install Dependencies
```bash
pip install flask
```

If a requirements.txt file is available:
```bash
pip install -r requirements.txt
```

### 6. Run the Application
```bash
python app.py
```

### 7. Open in Browser
Visit:
```text
http://127.0.0.1:5000
```
